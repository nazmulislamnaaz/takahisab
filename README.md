# Taka Hisab

Personal income, expense and budget tracker. Works offline, installs on your phone, no server.

Developed by **Nazmul Islam Naaz** - [nazmulislamnaaz@outlook.com](mailto:nazmulislamnaaz@outlook.com)

## Features
- Income and expense log with categories and accounts (Cash, bKash, Nagad, Bank)
- Monthly summary, budget vs actual, account balances
- Account sign up and sign in (stored on the device, passwords hashed)
- Backup and restore (JSON), CSV export
- Offline use and install to home screen

## Privacy
Data stays in your browser. It is never sent to any server. Back up from Accounts > Back up data.

## Hosting on GitHub Pages
1. Upload these files to the root of a public repository.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Open the link once online, then use Add to Home Screen.

## Updating
Change the files, then raise the version in `sw.js` (`taka-hisab-v4` to `v5`) so phones fetch the new version.
